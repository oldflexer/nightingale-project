# 🎙️ Nightingale

**Nightingale** — это Python-проект для автоматического сбора новостей с сайта Министерства обороны России, их сжатия через LLM, озвучивания локальной TTS-моделью и публикации аудиосообщений в Telegram-канале.

## 💡 Идея

Проект реализует полностью автономный конвейер:

1. **Парсинг** — извлечение свежих новостей с `mil.ru` (заголовки, ссылки, полный текст).
2. **Сжатие текста** — отправка собранных новостей в LLM (через OpenRouter) для получения краткой и выразительной дикторской выжимки.
3. **Синтез речи** — преобразование полученного текста в аудио с помощью локальной модели TTS (с поддержкой русского языка и клонирования голоса).
4. **Публикация** — загрузка готового аудиофайла в указанный Telegram-канал.

Вся логика написана на Python, что даёт гибкость, простоту отладки и возможность запуска как вручную, так и по расписанию.

## ✨ Возможности

- 🕸️ Парсинг статического и динамического контента (реализуется через `requests` + `BeautifulSoup` или `Selenium` при необходимости).
- 🧠 Интеграция с OpenRouter — доступ к моделям Arcee AI, GPT и другим LLM для качественного пересказа новостей.
- 🎧 Локальный TTS (например, Coqui TTS, Vosk или другой движок) — полный контроль над голосом, без внешних API-запросов.
- 🤖 Автоматическая отправка аудио в Telegram через Bot API.
- ⚙️ Простая настройка через файл `.env` (токены, параметры, пути).

## 📦 Требования

- Python 3.10+
- Docker (опционально, для изоляции TTS-сервера)
- Telegram-бот с правами на публикацию сообщений
- Аккаунт OpenRouter (для доступа к LLM)
- Локально установленная TTS-модель (например, XTTSv2)

## 📄 Лицензия

Проект распространяется под лицензией Apache 2.0.
